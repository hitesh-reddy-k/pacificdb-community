# PacificDB Community v1.0.0

PacificDB Community v1.0.0 aligns the engine, native CLI, Node.js client,
npm CLI, Java client, Python client, Helm chart, and packaging metadata on one
stable semantic version.

## Highlights

- Persistent pooled connections and batched `insertMany` support in the Node.js
  client and engine.
- A terminal-safe PacificDB ring-and-waves identity in both the npm and native
  interactive shells.
- Consistent `1.0.0` version reporting across packages and release tooling.
- WAL, recovery, RF3 replication, backup/restore, documents, vectors, and media
  remain included in the Community build.

## Qualification status

The version number does not replace release evidence. Physical power-loss
testing, independent security review, Windows signing, macOS signing and
notarization, and the remaining documented qualification gates must be attached
to the exact release revision before claiming universal production readiness.

See [the certification report](../COMMUNITY_P0_CERTIFICATION.md),
[release evidence contract](../RELEASE_EVIDENCE.md), and
[compatibility policy](../COMPATIBILITY.md).
