# PacificDB Community 1.2.0

A unified database for documents, vectors and media using shared durable WAL/LSM
storage. This version brings dense, sparse and named vectors, creation-time vector
schemas, bounded exact top-K, opt-in standalone HNSW indexing, metadata filtering
and lexical/vector hybrid ranking. It also improves incremental dense ANN
freshness, query-state isolation, SDK connection handling and Linux desktop icons.

## Packages and installation

Engine, CLI, Workbench, Node.js and Java packages use version **1.2.0**; Python
uses **1.2.0**. See [installation instructions](../../INSTALLATION.md) and the
[SDK guide](../../SDK_GUIDE.md) for setup, APIs and required runtimes. Use the
artifacts attached to this release and verify their `SHA256SUMS` before installing.

**Windows and macOS packages are unsigned by the release owner's decision. macOS
packages are not notarized.** Windows may display unknown-publisher/SmartScreen
warnings; macOS may block opening the application. Follow your organization's
software policy and the installation guide's per-application approval steps.
Checksums are not a code-signing certificate. Do not disable OS protections globally.

Java SDK downloads include the JAR and matching POM with coordinates
`in.pacificdb:pacificdb-client:1.2.0`; imports remain `io.pacificdb.*`.
Maven Central publication is deferred. GitHub downloads and registry availability
are separate; use only distribution channels independently confirmed as published.

## Scope and compatibility

Document, vector and media records retain the existing storage format and mutation
lifecycle. Use the documented standalone vector configuration. Distributed sharded
vector completeness, automatic ANN compaction and unrestricted schema alteration
are not supported release claims. Do not infer those capabilities from RF3 document
replication. Keep backups and test upgrades against copies of your own data.

Published RC.2 assets retain their original source and identities. They do not
contain all changes listed here. Report defects through the repository issue tracker
with package version, OS, reproduction steps and redacted diagnostics.
