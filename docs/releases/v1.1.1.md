# PacificDB Community v1.1.1

PacificDB 1.1.1 introduces database-first workflows across the native and npm
shells, Node.js, Python, Java, and Workbench. Existing project metadata and legacy
SDK/raw APIs remain available; no storage-format migration is required.

## Highlights

- Connect directly to a database with `pacificdb://` or verified-TLS
  `pacificdbs://` URLs.
- Create, select, and manage databases without mandatory project selection.
- Use expanded Python and Java CRUD, query, vector, media, backup, security, and
  administrative APIs.
- Use checksummed, bounded media transfer and explicit upload resume.
- Benefit from corrected Node.js pool scheduling and request ownership during
  connection failures and TLS-handshake timeouts.
- Use Workbench 1.1.1 with direct database navigation, generated CLI/SDK examples,
  and bounded Overview count loading.
- Build artifacts with an embedded, verifiable source revision.
- Resolve the Java SDK's Jackson dependency to patched version 2.18.10.

## Install

Download native packages and `SHA256SUMS` from this release. On Ubuntu/Debian:

```sh
sudo apt install ./pacificdb-community-1.1.1-linux-amd64.deb
pacificdb --version
```

Node.js 18 or newer:

```sh
npm install --global @pacificdb/cli@1.1.1
npm install @pacificdb/client@1.1.1
```

Python 3.10 or newer:

```sh
python -m pip install pacificdb==1.1.1
```

Workbench installers are published separately under
[`workbench-v1.1.1`](https://github.com/hitesh-reddy-k/pacificdb-community/releases/tag/workbench-v1.1.1).

## Upgrade and compatibility

Verify a full backup, stop clients and the engine, install matching 1.1.1 engine
and SDK packages, then confirm `pacificdb --version`. Stored project mappings and
data remain intact. Scripts that use the removed friendly project shell commands
or Workbench project screens must switch to database commands; legacy SDK/raw
project APIs remain available.

Windows and macOS artifacts are unsigned under an exception restricted to this
release. Verify `SHA256SUMS` before installation. See the
[website release notes](https://pacificdb.in/release-1.1.1.html),
[documentation](https://pacificdb.in/docs.html), and
[detailed engineering report](https://github.com/hitesh-reddy-k/pacificdb-community/blob/v1.1.1/docs/releases/CORE_ENGINE_OPTIMIZATION_1.1.1.md) for validation
scope, known performance trade-offs, and remaining risks.
