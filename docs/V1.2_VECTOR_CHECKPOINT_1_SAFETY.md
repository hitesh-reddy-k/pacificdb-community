Status: PASS for the exercised checkpoint scope. Full release: INCOMPLETE.

All changes remain uncommitted. Earlier exact-search work is preserved.

## A. Implementation

- `database_engine.cpp`: removed the quadratic legacy ANN graph/cache entirely.
  Exact ranking remains bounded and uses selective field decoding. `exact` always
  runs exact; `auto` permits safe exact fallback by default; explicit `ann`
  fails with `vector_index_unavailable: ABSENT` unless exact fallback is explicitly
  allowed. `allow_exact_fallback` must be boolean. Legacy environment settings
  cannot enable any builder. Successful server responses add execution metadata.
- `query_limiter.hpp/.cpp`: shared request-owned state replaces process-global
  truncation flags and active timer maps. Configuration and aggregate active-query
  count remain atomic shared budgets. RAII scopes restore previous worker state;
  queued closures retain shared ownership across request destruction.
- `query_cancellation.hpp/.cpp`, `connection_pool.cpp`, `server.cpp`: cancellation
  and limit scopes apply to each RPC, including persistent keepalive connections.
  A queued find timeout cancels its own token. Accepted asynchronous writes retain
  existing semantics. Aggregate results now expose request-local partial flags.
- `db_task_queue.cpp`, `db_task_queue_sharded.cpp`: propagate limits/cancellation
  and clear thread-local read contexts before and after each worker task, including
  exceptions. The partitioned queue uses the sharded implementation.
- `database_engine.cpp`: standalone reads now honor caller version floors rather
  than bypassing them with the cluster commit-index check. Cancelled document scans
  explicitly mark their own partial result; exact vector scans fail explicitly.
- `server.cpp`, `database_engine.hpp`, Node SDK: additive search execution metadata
  and fallback option. No authoritative format, WAL fsync or Raft acknowledgement
  change was introduced by this checkpoint.

Compatibility: explicit ANN now reports unavailability instead of invoking an
unqualified implementation. Auto uses the verified exact path within configured
limits. Callers must handle scan/time/cancellation/resource errors; no partial exact
answer is returned. A valid aggregate over a truncated scan now reports partial.
Python/Java option maps remain usable; no new typed vector feature is claimed.

## D. Reliability and remaining risks

Exercised WAL, restart, snapshot, media crash, RF3 and tenant tests passed. Storage
and replication remain authoritative. Request isolation passed the stated native,
queued and API concurrency workloads; this is not proof for every future queue.
The serialized result-byte limit is not a hard RSS reservation. Historical snapshot
MVCC, shard data movement and distributed vector completeness remain unqualified.

The separate unused HNSW class failed a dedicated statistics-reader/insertion TSAN
audit. A 10K random diagnostic had high recall, which does not qualify lifecycle,
memory, 100K/1M behavior or crash safety. Its race repair and index manager belong
to checkpoint 2. Public modes cannot reach that class in checkpoint 1.
