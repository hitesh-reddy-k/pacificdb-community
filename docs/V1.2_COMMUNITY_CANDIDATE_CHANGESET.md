## Current architecture and preserved behavior

Committed vector records, payloads and schemas use PacificDB's existing WAL/LSM,
Raft apply, snapshot and backup infrastructure. There is no second authoritative
vector store. Dense JSON arrays preserve float64 values; sparse-v1 records contain
explicit dimensions, sorted unique indices and finite float64 values. Named
spaces are stored with the record. No historical float64-to-float32 migration is
enabled. Packed exact float64, HNSW float32 and BM25 indexes are derived state.

The public native lifecycle and hybrid APIs require the explicit standalone
preview flag. Existing schema-less document/vector APIs remain compatible.
Collection schemas are immutable creation-time declarations; there is no online
schema migration. Multi-peer native vector catalogs/schemas and complete sharded
vector search remain gated. Existing document/media/RF3 operations continue through
their established paths; the regression evidence below establishes only the
exercised scenarios, not universal non-regression.

The quadratic legacy ANN builder is removed from supported routing. Exact search
uses bounded top-K, selective decoding, deterministic ties and explicit failures
instead of returning prefix rankings. Named native indexes require eligible source
certificates; authoritative result validation rejects changes during a query.
Incremental HNSW uses bounded committed-ID journals and per-index shared locks.
It can explicitly reject reads while catching up. Physical replacement history is
bounded; manual rebuild is required after exhaustion or loss of journal coverage.
Restart preserves definitions but requires explicit derived-index reconstruction.

## Operational risks and deployment decision

Mixed-write ANN freshness errors are availability failures even when they prevent
incorrect results. Review the completed benchmark's success counts alongside its
successful-query latencies. Static recall alone cannot qualify continuous writes.
Full HNSW reconstruction after restart and manual compaction may create long ANN
unavailability windows. Journal, graph and source reservations are bounded, but
complete hard tenant/process quotas and arbitrary workload RSS are not certified.

The Community scope accepts the documented per-index locking/manual maintenance
strategy; physically immutable incremental graphs and automatic compaction are
future capabilities. Quantization, PQ, disk-backed/mmap ANN, online schema migration
and distributed vector completeness are not represented as implemented.

The version remains **INCOMPLETE for production release**. A completed self-run
benchmark is suitable for technical review with its limitations, not independent
certification. Preparing local artifacts does not authorize commit, push,
publication or deployment. The existing release audit remains unchanged.
