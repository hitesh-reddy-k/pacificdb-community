01

Start your local database

After installing, run this in a terminal and keep it open.

pacificdb-local

Windows: use pacificdb-local.cmd. Local mode binds to 127.0.0.1:9000 with authentication off. Configure TLS and authentication before any network deployment.

02

Meet your shell

The native CLI is included. In a second terminal:

pacificdb ping
pacificdb shell
Prefer the npm CLI?

With Node.js 18+ installed, you can also use:

npm install --global @pacificdb/cli@beta

Both CLIs use the name pacificdb; your PATH decides which runs. The npm CLI connects to a running engine.

03

Give your app a connection

Install the Node.js client in your project.

npm install @pacificdb/client@beta

Save the example below as hello.mjs, then run node hello.mjs.

SMALL API. ROOM TO GROW.

Your first document.
The start of something.

Create a database and collection, then write and read a document with the published Node.js client.

@pacificdb/client ↗@pacificdb/cli ↗
hello.mjs
import { PacificDBClient } from '@pacificdb/client';

const db = new PacificDBClient({
  host: '127.0.0.1', port: 9000, database: 'hello'
});

await db.createDatabase();
await db.createCollection('ideas');
await db.insert('ideas', {
  id: 'first', title: 'Something worth building'
});

console.log(await db.find('ideas', { id: 'first' }));
