WHY PACIFICDB

One system of record.
More room to build.

PacificDB keeps related application data together without forcing you to operate a document database, vector store, media pipeline, and backup path as separate products.

011×

One path for every shape.

Write documents, embeddings, and resumable media through one database, one protocol, and one operational model.

02W

Recovery is engineered in.

WAL, LSM storage, compaction, checksums, snapshots, and crash recovery protect more than the happy path.

03R3

Distribution stays explicit.

RF3 Raft handles elections and follower catch-up; sharding controls placement, migration, and rebalance.

04⌂

Run where your data belongs.

Native packages, Docker, Kubernetes, Helm, CLI tools, and three SDKs carry you from local work to controlled deployments.

FROM ZERO TO YOUR FIRST WRITE

Start local.
Build outward.

Install the engine, open the shell, and connect an application without handing your data to a hosted service.

Read the documentation →
01

Start one local engine

Run one command to launch the loopback engine and enter the interactive shell.

pacificdb

Local mode binds to 127.0.0.1:9000. Configure TLS and authentication before any network deployment.

02

Shape your first data

Create a database and collection, then write and find a JSON document:

create database hello\nuse hello\ncreate collection ideas\ninsert ideas {"id":"first","title":"Hello PacificDB"}\nfind ideas {"id":"first"}
03

Connect the application

Add the published beta.13 Node.js client and use the same local engine from code.

npm install @pacificdb/client@beta

Save the example below as hello.mjs, then run node hello.mjs.

ONE PROTOCOL. THREE CLIENTS.

Meet your data
where your code lives.

Connect through Node.js, Python, or Java. This first write uses the published beta.13 Node.js client and the Community JSON-over-TCP protocol.

@pacificdb/client ↗@pacificdb/cli ↗
hello.mjs
import { PacificDBClient } from '@pacificdb/client';

const db = new PacificDBClient({
  host: '127.0.0.1', port: 9000, database: 'hello'
});

await db.createDatabase();
await db.createCollection('ideas');
await db.insert('ideas', {
  id: 'first', title: 'Something worth building'
});

console.log(await db.find('ideas', { id: 'first' }));
