PRE-RELEASE V1.2 · RC.2 · COMPANY TESTING

One database.
More ways to search.

PacificDB 1.2.0-rc.2 is published for external evaluation. Documents, vectors and media retain shared authoritative WAL/LSM storage.

Available now. Release and packages · SHA-256 checksums · Installation. Four desktop targets are install-tested: Ubuntu 24.04 x64, Windows x64, macOS 15 Intel and Apple Silicon. Full production qualification remains incomplete.

What changed in v1.2?

Added

  • Dense, sparse and named vectors, immutable creation-time schemas and matching SDK operations.
  • Opt-in standalone flat exact/HNSW lifecycle, bounded dense incremental maintenance and BM25/RRF hybrid retrieval.
  • Consistent candidate packages and installed-package verification for native tools and Node/Python/Java SDKs.

Removed

  • Unsafe legacy all-pairs ANN selection from supported search routing.
  • Process-global query-limit state that could mix concurrent requests.

Improved

  • Bounded exact ranking, selective vector decoding and authoritative point-read/cache correctness.
  • Storage failure/recovery and credential-log handling, with scoped regression tests.
  • RC.2 fixes short-window Workbench navigation and Linux installer integration.

Install and integrate

Workbench installers bundle engine and CLI. @pacificdb/client@1.2.0-rc.2 and @pacificdb/cli@1.2.0-rc.2 are on npm. Python 1.2.0rc2 wheel and Java 1.2.0-rc.2 JAR/POM are downloadable from GitHub. Python is also published on PyPI as pacificdb==1.2.0rc2. Maven Central publication still awaits owner setup; use the GitHub JAR/POM for Java.

Use the Python client from FastAPI and the Node.js client from a Next.js Node server runtime. The Node package is JavaScript ESM and does not ship TypeScript declarations. Do not expose database credentials in browser code.

Known limitations and qualification

This is a prerelease, not a stable production release. Native vector features stay opt-in and standalone. Strict ANN can be unavailable during writes; graphs require explicit rebuilding after restart. Automatic graph compaction, complete distributed vector search, advanced compression/disk ANN and full production/upgrade/power-loss/security qualification remain incomplete. Stable signing/notarization and managed-device endpoint-policy compatibility are not fully qualified.

Scoped RC.2 checks passed 78 checkpoint checks/50 CTest cases, installed SDK tests, Community/disk-full/RF3 regressions, four public desktop installations and targeted separate TSAN/ASan/UBSan jobs. Exact verification scope.

Benchmark status

The post-publication RC.2 comparison uses 1M GloVe-25 cosine vectors against PostgreSQL 18.6 + pgvector 0.8.7, with 1,000 held-out queries per round. The declared study has completed, including mutation/crash/rebuild phases. The results include failed strict ANN read availability during writes; completion is not production qualification. See the published report and reproducible evidence. This is a project-run comparison, not independent certification; timings depend on hardware, cache, dimensions, payload and settings.
